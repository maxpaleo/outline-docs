Create your first note in Outline for macOS. If you have not installed it yet, [download it from the Outline website](https://www.outline-app.co/).

## Write your first note

1. Open Outline and select **New note**. You can also use **New Note** in the sidebar's creation menu.
2. Give the note a name, such as `Today`.
3. Write a sentence about your day or a project. Outline saves the note as you work.

Your note appears in the sidebar. Select it there to return to it later.

## Format and add to the note

Select a few words you have written. A toolbar appears near the selection; use **Bold** or **Italic** to emphasize them.

To add a different kind of content, start a new line and type `/`. Choose a command from the menu. For example, try **Heading 2** for `Morning`, **Checkbox List** for tasks, and **Table** for items you want to track. You can type after `/` to narrow the menu.

You do not need to know Markdown to use the editor. If you already use Markdown, familiar shortcuts also work. See [Writing and formatting](</docs/v0/notes/writing-and-formatting>) for more.
