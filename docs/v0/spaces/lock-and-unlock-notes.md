---
title: Lock and unlock notes
description: Restrict access to selected notes inside Outline with a vault password.
---
Lock a note so it can be viewed or edited in Outline only while the vault is unlocked. Locking notes requires Pro.

## Lock a note

1. Right-click the note in the sidebar and select **Lock**.
2. If you have not set a vault password, set one when prompted. One vault password works across your Spaces.

Keep your password somewhere safe. Outline does not currently offer password recovery.

## View or unlock a note

Open a locked note and select **Unlock vault**, then enter your password. If system unlock is available, you can use it instead. The vault stays unlocked for the current app session until you lock it again.

To remove the lock from a note, right-click it in the sidebar and select **Unlock**. You may need to unlock the vault first.

Open **Settings** at the bottom of the sidebar to select **Lock Vault** or **Unlock Vault** at any time.
