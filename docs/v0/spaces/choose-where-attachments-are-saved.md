Each Space can use its own folder for images and other files you add to notes. The default folder is `Attachments`.

New Spaces hide the default `Attachments` folder from the sidebar. The files remain available to notes and other Outline features.

## Choose an attachment folder

1. Open the Space selector.
2. Select **Advanced**, then **Settings**.
3. Under **General**, find **Attachments folder**.
4. Enter a path relative to the Space, such as `Media/Uploads`.
5. Select **Save**.

Outline creates the folder when you add the first attachment to it.

## What happens to existing attachments

Changing the folder affects new attachments only. Outline does not move existing files or update their paths. Existing attachments continue to open from their original locations.

Changing the attachment folder does not update the Space's visibility rules. A new folder may therefore appear in the sidebar unless it matches another hidden pattern. Configure its visibility separately under **Content visibility**, or hide it from the folder's context menu.
