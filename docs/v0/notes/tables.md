Tables keep related details together in a note. Each row is an item, and each column says what kind of information it holds. For a Café renovation, you might track an owner, status, budget, due date, and whether work is blocked.

## Add a table

1. In a note, start a new line and type `/`.
2. Choose **Table**. Give the table a title, such as `Café renovation`.
3. Rename the starter columns for the details you want to track. Add rows for the items in your project.
4. Use a column's menu to choose its input type, then fill in its cells.

## Choose column inputs

The input type controls how you enter a cell. Choose from these options in the macOS note editor:

- **Text** for a short item name; **Textarea** for longer details.
- **Note** to select or create a linked note.
- **Number** for a budget or quantity.
- **Checkbox** or **Switch** for a yes-or-no value, such as Blocked.
- **Date** for a due date; **Date &amp; time** when the time matters too.
- **Select** for one status; **Multi-select** for several tags. You can add your own choices.
- **Link** for a web address.
- **Image** for an attached picture; **Image URL** for a picture at a web address.

Use **Edit column** to set a default value, add a description, and adjust the value display where that type supports it. Image columns can show thumbnails or featured images. You can also change a column's width and how many lines of cell text it shows.

## Find and arrange information

Use the search control in the table header to show matching rows. It reports how many rows match; clear the search to see the full table again.

Open a column menu to sort or group rows by that column. Grouping by **Status**, for example, gathers items under each status; you can collapse a group to focus on the others. You can also reorder rows and columns, copy selected cells or rows, and duplicate or delete rows.

The table's **…** menu has **Columns** to show or hide columns, plus **Copy**, **Duplicate**, and export choices for CSV and JSON. It also has **Copy link** so you can refer to the table elsewhere. A row's menu offers its own **Copy link**. Hidden columns are still part of the table; open a row to edit all its fields, including hidden ones.
