Mark up images in Outline for macOS to point out details or explain an idea. You can edit local PNG and JPEG images in an editable note.

## Open the editor

Open an image in your note, then select the **pencil** in the top-right corner of the viewer.

## Add and adjust annotations

Choose a tool from the left toolbar to add shapes, text, lines with optional arrowheads, freehand drawings, or polygons. For a polygon, click its first point to finish it.

Use the **selection arrow** to select an annotation and move or resize it. The separate toolbar below the tools shows its available properties, such as color, opacity, stroke width and style, arrowheads, or text size. Shape and text tools also offer different types.

Pinch on your trackpad or use the bottom zoom controls to zoom. When zoomed in, use two fingers to move around the image.

## Save or cancel

Select the **checkmark** in the top-right corner to save. Select **X** to cancel; if you have unsaved changes, Outline asks whether to discard them.

Your original image stays unchanged. The note displays the annotated version. Open it and select the pencil again to continue editing the annotations. Later saves update that version instead of creating another copy each time.
