Write directly in a note, then use the editor to organize and emphasize your ideas. For a simple daily note, you might add a `Morning` heading, write a few lines, and make a task list below it.

## Format selected text

Select text to open the floating toolbar. Choose **Bold** or **Italic** to emphasize it, or choose another available formatting action. Select the text again to change its formatting.

## Insert an element

Start a new line and type `/` to open the command menu. Choose a command, or type its name to find it. For example, choose **Heading 2**, **Checkbox List**, or **Table**. The menu inserts the element at your cursor.

Use **Checkbox List** for a straightforward checklist. **Task List** adds richer task fields.

## Use Markdown if you like

Markdown is a way to format plain text with short marks. For example, type `## Morning` on a new line to make a heading, or `-` followed by a space to start a bullet list. You can use the toolbar and `/` menu instead whenever you prefer.
