Note links connect related information without copying it. They use the same link badge in notes, AI Chat, and tables.

## Add a link in a note

1. Type `/` and choose **Note Link**.
2. Search for a note.
3. Select the note you want to link.

You can also type `[[` to open the same note selector.

The link appears as a badge in the editor. You can select and copy the badge with the surrounding text.

To change the linked note or its label, right-click the link and select **Edit**. Select **Remove** to remove the badge.

## Add a note to an AI Chat message

1. Select the **+** button in the chat composer.
2. Search for the note you want to include.
3. Select the note.

The note appears as a link badge in your message. You can add more than one note before sending it.

## Use note links in tables

In a table column that uses the **Note** input type, select a cell and search for a note. Choose **Create note** if the note does not exist yet.

Links to a table row or another specific part of a note open the note at the linked content.

## Open and manage a link

Select a link badge to open the note in a preview. When you right-click the link, you can also open the note in a new tab or window, show it in Finder, or copy its path. Available actions depend on where the link appears.

If the linked note includes a description, hover over the badge to view it. A link may appear unavailable when its note was moved, deleted, or belongs to a Space that Outline cannot access.
