Use Excalidraw to create diagrams, flows, sketches, and other visual notes inside an Outline Space. Each drawing is stored as an `.excalidraw` file alongside your other files.

## Create a drawing

1. Open the Space where you want to add the drawing.
2. Right-click an empty area of the sidebar to create it at the Space root, or right-click a folder to create it there. Select **New Drawing**.
3. Rename the new drawing as needed.

## Edit a drawing

Open the drawing from the sidebar, then use the toolbar to add shapes, arrows, freehand lines, text, and images. You can select and move elements, change their appearance, erase them, or organize them on the canvas.

Outline saves changes automatically as you work.

## Work with AI agents

Outline AI Chat and external AI clients connected through Outline MCP can create, preview, and update drawings. Tell the agent which drawing you mean and what you want to change. For example:

> Create `API flow.excalidraw` with a client, an API server, and a database.

> Preview `API flow.excalidraw`.

> Add an error-handling path to `API flow.excalidraw`.

If you work with more than one Space, include the Space name. To create a drawing inside a folder, create the folder first. Creating drawings through Outline MCP requires **Outline tools 0.0.2 or later**.
