Export a note as a PDF when you want a copy that is easy to share or print. PDF export is available with Outline Pro on macOS.

## Export the note

1. Open the note and choose **Export as PDF…** from its **…** menu.
2. Wait for Outline to prepare the PDF, then check the preview. The page size is **A4 portrait**.
3. Select **Export**, choose where to save the file, and confirm.

The PDF is a snapshot of one note. If you edit the note later, export it again to make an updated PDF.

## Check the preview

Some interactive or rich elements may appear as a simpler representation in the PDF. If an image cannot be loaded, the export shows a visible placeholder. Check the preview before saving.

For a very large note or one with many images, Outline may show an error instead of exporting. Split the note or reduce its image content, then retry.
