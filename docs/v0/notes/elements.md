Elements help you give each part of a note the right shape. Type `/` on a new line to open the insertion menu, then choose an element or search for its name. Some choices appear only when they are available at your cursor.

# Core elements

## Text

Write regular paragraphs. Press Return to start another paragraph.

## Headings

Use **Heading 1**, **Heading 2**, and **Heading 3** to organize sections and subsections within a note.

## Lists

Use a **Bullet List** for related ideas and a **Numbered List** for steps that have an order.

- Gather ideas
- Pick one to develop

## Checklists and tasks

A **Checkbox List** lets you tick off simple items. A **Task List** is useful when each task needs more detail.

## Table

Keep related items in rows and choose what each column holds. For example, a project table can have Owner, Status, and Due date columns. See [Tables](</docs/v0/notes/tables>).

## Links

Use **Link** for a web address and **Note Link** to point to another note. See [Link to notes](</docs/v0/notes/link-to-notes>).

## Image

Add a picture to the note. On macOS, you can add arrows, shapes, text, and drawings to local PNG and JPEG images. See [Edit images](</docs/v0/notes/edit-images>).

# More elements

## Emoji and highlight

Add an **Emoji** as a visual cue, or use **Highlight** to emphasize a short passage.

## Blockquote and callout

Use a **Blockquote** for quoted text. Use a **Callout** to draw attention to a tip or other important information.

> Keep the first version simple.

## Columns

Place content side by side, such as two options you want to compare.

## Code Block

Keep code in its own block and choose a language for highlighting.
