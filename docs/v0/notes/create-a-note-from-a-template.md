Templates let you start notes with content you use often, such as a checklist or meeting agenda. Templates are available in Outline for macOS.

## Create a note

1. Open the Space where you want to create the note.
2. Select the **+** button in the sidebar, then **From template**.
3. Select a template, then select **Create**.
4. Rename the new note using its focused title, then start editing.

**Global** templates are available in every Space on this Mac. **This space** templates are available only in the current Space.

Outline names the new note `Untitled`, or adds a number such as `Untitled 1` if that name is already taken. Selecting a template does not create a note until you choose **Create**.

## Work with your copy

The new note is an independent copy. Editing it does not change the template. Editing a template affects future notes only.

Outline includes editable Tasks, Checklist, and Meeting notes templates when it first sets up your template library. You can add your own or change these starters.

Links, images, and attachment references keep their original destinations. Referenced files are not copied, so relative paths may point somewhere different when you use a template in another Space.
