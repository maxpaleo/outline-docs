## Create a drawing

1. Open the Space where you want to add the drawing.
2. To create it at the root of the Space, right-click an empty area of the sidebar and select **Create drawing**.
3. To create it inside a folder, right-click the folder and select **New drawing**.
4. Rename the new drawing as needed.

## Edit a drawing

Open the drawing from the sidebar, then use the toolbar to add shapes, arrows, freehand lines, text, and images. You can select and move elements, change their appearance, erase them, or organize them on the canvas.

Outline saves changes automatically as you work.

To inspect or update a drawing with AI, see [[Help Center/Public/Excalidraw/Excalidraw with AI agents|Use Excalidraw with AI agents]].
