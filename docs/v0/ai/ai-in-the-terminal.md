Use Outline’s Terminal to run an AI coding agent in the current Space. Install the agent and sign in to it before you start.

<!-- outline:block id="img_9c8b3d72-770" type="image" version="1" assetId="Attachments/ai-in-terminal.png" src="Attachments/ai-in-terminal.png" alt="ai-in-terminal.png" -->
![ai-in-terminal.png](Attachments/ai-in-terminal.png)
<!-- /outline:block -->

1. Open the Space you want the agent to work in.
2. In the workspace, select the **+** button beside the Chat and Terminal tabs, then choose **New Terminal**. If no tab is open, use the **+** button in the middle of the workspace.
3. Enter the installed agent's command, such as `codex` or `claude`, and press Return.

If your Space has a **Commands** resource group, you can also select the composer's **+** button and choose a configured starter command. The available commands depend on the Space.
