description: Enable Codex and connect your ChatGPT account for AI Chat in Outline.

Outline’s built-in AI Chat is powered by the Codex agent harness. Connect a ChatGPT account in Outline before starting your first chat.

1. Open **Settings &gt; AI** in Outline.
2. If Codex has not been set up on this Mac, select **Set up Codex** and wait for setup to finish. If a previous attempt failed, select **Retry setup**.
3. If Codex is installed but disabled in Outline, select **Enable Codex in Outline**.
4. If sign-in options appear, choose one and complete the ChatGPT sign-in steps. If you see **Waiting for ChatGPT sign-in…**, finish in the opened browser page. Select **Open sign-in page** if you need to reopen it, and enter any code shown in Outline.
5. Return to Outline and wait for **Connected** to appear with your account.

If Codex is already enabled or your account is already connected, Outline skips those steps. If installation or connection fails, follow the retry or repair action shown in the Codex section, then try again.
