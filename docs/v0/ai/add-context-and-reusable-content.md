Resource items let you add reusable content from your Space, such as skills, Terminal commands, and note templates, to Chat or Terminal messages. You can also reference notes, folders, and Outline context.

## Add a resource

1. Select the **+** button in the composer.
2. Open a resource group.
3. Search for the item you want.
4. Select the item to add it.

Some resource groups display a shortcut, such as **@**, **$**, or **/**. Type the shortcut in the composer to open that group directly.

## Default resource groups

New Spaces start with these resource groups:

- **Notes and folders** — Find content in the current Space.
- **Context** — Reference the current note or the whole Space.
- **Templates** — Find reusable note templates.
- **Commands** — Find reusable Terminal commands.
- **Codex Skills** — Use available Codex skills when the provider is enabled.

You can rename, reorder, disable, remove, or add file groups such as **Templates** and **Commands** in each Space. The menu reflects that Space's configuration. Outline supplies **Notes and folders** and **Context** independently of those file groups.
