# Start an AI chat

Use AI Chat to ask questions, work with your notes, or complete tasks in the current Space.

## Start a chat

1. Open the Space you want to work in.
2. Select the **+** button in the workspace, then choose **New Chat**.
3. Write your message in the composer.
4. Select **Send message**.

If prompted, connect your ChatGPT account before continuing.

## Choose how the AI works

- **Ask** can answer questions and inspect notes without making changes.
- **Agent** can edit notes and use tools to complete tasks.
- Use the model selector to choose a model, or leave it on **Auto**.

You can also select the **+** button in the composer to add notes, folders, files, or other resources to your message.

Learn more in [[docs/v0/resource-items/use-resource-items]].
