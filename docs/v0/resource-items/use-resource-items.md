# Use resource items

Resource items make it easy to add notes, folders, reusable content, commands, and Codex Skills to your work.

> Resources are available in both the Chat composer and Terminal composer.

## Add a resource

1. Select the **+** button in the composer.
2. Open a resource group.
3. Search for the item you want.
4. Select the item to add it.

Some resource groups display a shortcut, such as **@**, **$**, or **/**. Type the shortcut in the composer to open that group directly.

## Available resource groups

The resources available can vary by Space, but the default groups are:

- **Notes and folders** — Find content in the current Space.
- **Context** — Quickly reference the current note or the entire Space.
- **Templates** — Find reusable content prepared for the Space.
- **Commands** — Find reusable command templates prepared for the Space. In Terminal, type `/` to open the configured Commands group. A command can insert text for review or run immediately.
- **Codex Skills** — Use specialized Codex workflows. Selecting a skill adds it in its normal `$skill-name` format.

## Resource warnings

If Outline cannot load or understand one or more resources, a **Warnings** section appears at the bottom of the resource menu.

Open it to see what went wrong and which resource caused the warning. Warnings do not prevent other resources from working.

To change which resource groups appear, see [[docs/v0/resource-items/configure-resource-items]].
